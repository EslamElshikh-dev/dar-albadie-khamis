# دار البديع للحجامة — فرع خميس مشيط

موقع عربي متعدد الصفحات للمركز، مبني باستخدام Next.js. بيانات التواصل والصور مستمدة من ملف فرع خميس مشيط العام على Google Maps، وصور `public/images` من قسم «مِن المالك» في الملف. راجع الملكية والمعلومات مع إدارة المركز قبل إضافة خدمات أو ادعاءات صحية جديدة.

## التشغيل

```bash
npm install
npm run dev
```

## النشر

اربط المستودع بمشروع Vercel. إذا تغير نطاق `vercel.app`، حدّث `SITE_URL` في إعدادات المشروع وأعد النشر؛ تُستخدم القيمة للروابط القانونية والسكيما وملف sitemap.

بيانات المركز وروابط الحجز موجودة في `lib/site.ts`، والخدمات في `lib/services.ts`.

## طلبات المواعيد

- `/booking`: نموذج طلب الموعد العام. يُسجّل الطلب داخل الموقع ويعيد رقمًا مرجعيًا، ثم يؤكد الفرع الموعد والتكلفة مع العميل. الفترات تفضيلات وليست مخزون مواعيد مؤكدة.
- `/booking/manage`: متابعة الطلبات وتحديث حالتها بعد التواصل. الصفحة غير قابلة للفهرسة وتتطلب اسم مستخدم وكلمة مرور؛ لا تعرض واجهة البيانات أي سجلات دون جلسة صالحة.
- يُستخدم مخزن Vercel Blob خاص بفرع خميس مشيط. يحتاج الخادم `BLOB_READ_WRITE_TOKEN` و`BOOKING_ADMIN_KEY` لتوقيع الجلسات، و`BOOKING_ADMIN_USERNAME` و`BOOKING_ADMIN_PASSWORD_HASH` للتحقق من الدخول. تُضبط القيم في إعدادات Vercel فقط، ولا تُحفظ في المستودع ولا في متغيرات `NEXT_PUBLIC_`. كلمة المرور محفوظة كتجزئة scrypt مع ملح عشوائي، ولا تقبل واجهة الدخول مفتاح التوقيع كبيانات دخول.
- يحصل العميل على إيصال بعد نجاح الحفظ فقط. يحافظ مفتاح الطلب على عدم تكرار الحفظ عند إعادة المحاولة بنفس البيانات.
- لا يجمع النموذج تاريخًا صحيًا أو مستندات طبية. لا تُسجّل بيانات التواصل في سجلات التطبيق، ولا تُرسل إشعارات أو رسائل آلية إلى العملاء.
- يتابع مسؤول الفرع الطلبات من لوحة الإدارة ويتصل بالعميل للتأكيد. لا تُرسل الصفحة رسائل بريد أو واتساب تلقائية.

التحقق: `npm test`، ثم `npm run build`. تشمل الاختبارات تواريخ السعودية، الجمعة، الفترات الماضية، أرقام الجوال، الموافقة، الجلسات الموقعة، مصدر الطلب، وحجم البيانات.
